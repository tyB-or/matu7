# Matu7 安装指南

## 系统要求

### 硬件要求
- CPU：1GHz及以上处理器
- 内存：2GB及以上
- 硬盘：500MB可用空间

### 软件要求
- **操作系统**：
  - Windows 7/8/10/11
  - macOS 10.13及以上版本
  - Linux（主流发行版如Ubuntu、Debian、CentOS等）
- **浏览器**：支持现代浏览器（Chrome、Firefox、Edge等）

## 下载与安装

### Windows 系统

1. 从项目的 [Releases](https://github.com/用户名/matu7/releases) 页面下载最新的Windows版本（`matu7-windows-amd64.zip`）
2. 解压下载的文件到您选择的目录
3. 双击 `matu7.exe` 文件启动程序
4. 程序将自动在默认浏览器中打开 `http://localhost:58080`

### macOS 系统

1. 从项目的 [Releases](https://github.com/用户名/matu7/releases) 页面下载最新的macOS版本（`matu7-darwin-amd64.zip`）
2. 解压文件到您选择的目录
3. 打开终端，进入解压后的目录
4. 执行命令授予程序可执行权限：
   ```bash
   chmod +x matu7
   ```
5. 执行命令启动程序：
   ```bash
   ./matu7
   ```
6. 程序将自动在默认浏览器中打开 `http://localhost:58080`

### Linux 系统

1. 从项目的 [Releases](https://github.com/用户名/matu7/releases) 页面下载最新的Linux版本（`matu7-linux-amd64.tar.gz`）
2. 解压文件到您选择的目录：
   ```bash
   tar -xzf matu7-linux-amd64.tar.gz
   ```
3. 进入解压后的目录：
   ```bash
   cd matu7
   ```
4. 执行命令授予程序可执行权限：
   ```bash
   chmod +x matu7
   ```
5. 执行命令启动程序：
   ```bash
   ./matu7
   ```
6. 程序将自动在默认浏览器中打开 `http://localhost:58080`

## 首次运行配置

### 初始设置

1. 首次启动Matu7后，程序会自动在当前目录下创建以下文件夹：
   - `config`：存储配置文件
   - `notes`：存储笔记文件
   - `tools`：默认工具库目录

2. 浏览器将自动打开登录页面（`http://localhost:58080/login`）

3. 使用默认用户名和密码登录：
   - 用户名：`admin`
   - 密码：`admin`

4. 首次登录后，强烈建议修改默认密码（目前需要手动修改配置文件）

### 工具库设置

Matu7会自动将当前目录下的`tools`文件夹设置为默认工具库。如果您希望使用其他目录作为工具库，可以通过以下步骤添加：

1. 登录系统后，点击界面上方的"添加根目录"按钮
2. 在弹出的对话框中输入或选择新的工具库根目录路径
3. 点击"确定"按钮，系统将自动扫描并加载该目录下的工具

### 工具库结构

为了让Matu7正确识别您的工具，请按照以下结构组织您的工具库：

```
/tools/
├── 分类1/          (<- 这是工具分类目录)
│   ├── 工具1/      (<- 这是具体的工具目录)
│   │   └── ... (工具的可执行文件等)
│   └── 工具2/
│       └── ...
└── 分类2/
    ├── 工具3/
    └── ...
```

例如：

```
/tools/
├── 扫描工具/
│   ├── nmap/
│   │   └── nmap.exe
│   └── masscan/
│       └── masscan.exe
└── 漏洞利用/
    ├── metasploit/
    └── ...
```

## 端口配置

Matu7默认使用`58080`端口。如果此端口已被占用，您可以通过以下方式修改：

1. 打开`main.go`文件
2. 找到以下代码行：
   ```go
   port := "58080"
   ```
3. 将端口号修改为您希望使用的端口
4. 重新编译程序

## 常见安装问题

### Windows 系统问题

#### 程序无法启动

**问题**：双击程序后没有反应  
**解决方案**：
1. 尝试以管理员身份运行程序
2. 检查是否有杀毒软件阻止程序运行
3. 确认是否已安装.NET Framework

#### 浏览器未自动打开

**问题**：程序启动后浏览器未自动打开  
**解决方案**：手动在浏览器中访问 `http://localhost:58080`

### macOS 系统问题

#### "无法打开应用程序"错误

**问题**：macOS显示"无法打开应用程序，因为它来自身份不明的开发者"  
**解决方案**：
1. 在访达中找到应用程序
2. 按住Control键并点击应用程序图标
3. 从快捷菜单中选择"打开"
4. 在对话框中点击"打开"

#### 权限问题

**问题**：出现"权限被拒绝"错误  
**解决方案**：确保已正确设置可执行权限：`chmod +x matu7`

### Linux 系统问题

#### 缺少依赖库

**问题**：启动程序时提示缺少某些库文件  
**解决方案**：安装所需的依赖库，例如：
```bash
# 在Debian/Ubuntu系统上
sudo apt-get install libgtk-3-0 libwebkit2gtk-4.0-37

# 在CentOS/RHEL系统上
sudo yum install gtk3 webkit2gtk3
```

#### 权限问题

**问题**：无法执行程序  
**解决方案**：确保文件具有执行权限：`chmod +x matu7`

## 升级指南

升级到新版本的Matu7时，请按照以下步骤操作：

1. 备份您的配置和笔记：
   - 复制`config`目录
   - 复制`notes`目录

2. 下载并解压新版本的Matu7

3. 将备份的`config`和`notes`目录复制到新版本的目录中

4. 启动新版本的程序

5. 验证您的配置和笔记是否正确加载

## 卸载指南

Matu7是便携式应用程序，卸载非常简单：

1. 关闭Matu7程序（如果正在运行）
2. 删除Matu7的程序目录
3. 如果您希望保留配置和笔记，可以备份`config`和`notes`目录
