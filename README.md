# Matu7 渗透测试工具管理

Matu7：使用web界面管理本地的离线工具和常用的网页工具，具备更细化的管理操作。（mac版）


## 安装和使用

1.创建一个空文件夹
2.复制前端资源（public）目录和插件(extend)目录到创建的空文件夹中。(这两个同级)
3.复制主程序到空文件夹中（和上面的同级目录）
4.mac终端中运行：./matu7
5.输入工具库的路径


注意：
工具库目录规则：

|---工具库根路径（toolKu）
|-------工具分类目录(scan)
|-----------具体工具目录(nmap)
|--------------工具的相关文件（nmap的执行文件等）

## 功能介绍
1.前端相关资源都已下载至工具中
2.前端无缓存设计，方便工具的即时变动。【工具变动，前端立即同步变化】
3.前后端-本地关联设计，每次启动都是对本地工具的实时映射，使用中也可以热更新。
4.无数据库设计，方便后续迁移。

### 离线工具介绍
- 根目录管理：
    1.支持多根目录管理，每个根目录有独立的配置文件，支持新增、切换、删除；（管理多个工具库）；
    2.添加新根目录时，会自动复用已有同名工具的配置，但是路径信息会自适应。（整理工具场景适用）；
    3.不同库之间，同库之间，工具可自由挪动位置，配置信息和笔记信息自动同步。所有库之间的工具笔记都放在notes/offline_tools下面集中存储。
    4.所有库之间同名工具共用一个配置，一个笔记。（笔记强关联工具名称，修改工具名称会新建txt,原来的还在。）
    5.工具启动状态下手动整理本地工具，点击刷新工具，右上会显示工具的变动信息。工具非启动状态下整理工具，重新启动会自动更新相关工具信息，不会显示变动信息。
    6.点击红色垃圾箱按钮，会删除根配置文件（逻辑上），本地还在。

- 左侧分类： 
    1.分类信息关联本地工具的分类（分类文件夹的名称）【排序问题请自行通过命名解决】，点击自动切换分类视图。每个分类右边是工具数量统计。工具开启状态下，分类名称支持修改，修改后，点击刷新工具会显示变迁信息，工具关闭状态下修改分类信息，下次打开自动更新配置信息，前端界面、卡片配置、笔记保持自适应。【注意，工具命令需要重新修改-后续计划也设置成自动适应】

- 工具卡片：
    1.图标：从工具的来源url自动获取图标，或者使用自定义的图标，图标文件位于：public/icons/offline。
    2.工具名称，默认是工具文件夹的名称。可以修改,名称修改不影响其他功能。
    3.编辑按钮，编辑卡片的相关信息：增加标签的时候会模糊显示已有类似标签；增加关键路径显示，帮助构建命令使用；文件浏览器，点击复制到命令框，方便构建命令；自定义工具图标。
    4.删除按钮：删除本地工具文件夹和配置信息。
    5.显示分类信息/工具名称
    6.使用次数统计，（逻辑，点击执行按钮的次数）
    7.url：离线工具的来源信息或者工具的官网。
    8.工具标签：可以编辑，多维度的管理工具，点击标签显示标签分类视图。
    9.工具描述信息：工具的描述信息，无论多长都只在有限区域显示，点击描述区域，弹出描述悬浮框，点击框外区域自动消失。
    10.时间：创建时间和最后一次使用时间。
    11.执行按钮：点击会执行自定义的命令，启动cmd工具，gui工具等，（结合插件可以在启动cmd界面的时候打印常用命令）
    12.目录：点击打开工具的目录
    13.笔记：点击右侧弹出笔记编辑框，笔记过长会滚动，点击框外自动保存和缩回。笔记位置：notes/offline_tools


- 搜索：
    2种方式
        输入文字会从工具名称、描述、分类中模糊搜索
        输入标签：xxx,会从标签中模糊搜索
        友好的搜索结果反馈


### 网页工具

- 添加工具按钮：
    url填写后会自动获取图标作为卡片图标展示；输入分类会自动适应前端显示和后端配置；标签支持界面点击快速搜索；工具图标支持自定义，优化图标的选中逻辑，默认打开public/icons/websites，图标获取递进逻辑：网页图标-默认图标-内置库图标；完成信息编写后自动生成卡片，相关统计信息自动更新，左侧会适应填写的分类信息，点击切换分类视图。

- 网页工具卡片：
    图标：默认从工具的网页获取，也可自定义。（获取逻辑写了个寂寞，当时脑子怎么想的.....）
    名称：可自定义，关联网页工具的笔记，随便修改，笔记文件自适应同步更新名称。
    编辑按钮：修改相关信息，都可修改，界面和相关配置会自适应。
    删除按钮：删除工具和相关配置信息
    网址：工具的网址，过长省略
    使用次数：只统计点击打开按钮的次数。
    标签：可修改，点击会进行标签快速搜索。
    描述：工具的描述信息，无论多长都只在有限区域显示，点击描述区域，弹出描述悬浮框，点击框外区域自动消失。
    时间：创建时间和最后一次使用时间。【时间逻辑有问题，后面再改】
    打开按钮：点击打开网页工具，关联使用次数。
    笔记：网页工具相关的备注信息，点击打开的是：notes/web_tools/{工具名称}.txt，点击右侧弹出笔记编辑框，笔记过长会滚动，点击框外自动保存和缩回。（多余设置：点击保存按钮保存笔记、笔记状态显示）

- 搜索框：
    2种模式：普通搜索，标签搜索。
    标签搜索：模糊从所有标签中进行搜索
    普通搜索：从工具名称、描述、分类、工具url中进行搜索。








### 网页笔记
- 记录平时复现的参考博客，方便后续遇到快速查找，增加标题、分类、工具等信息，通过搜索快速定位url，然后根据记录的工具名称在离线工具库中查找再调用。
